# Security

Please report a security problem privately through GitHub's form:
https://github.com/HumanGenome/Doorman/security/advisories/new

There is no security email address. Do not open a public issue for a security problem.

Doorman runs inside a Schedule I dedicated server. It opens no port and runs no listener: it
reads one settings file and writes one status file in the server's `UserData` folder. Reports
about the game itself or about S1DedicatedServers belong with their own developers.
